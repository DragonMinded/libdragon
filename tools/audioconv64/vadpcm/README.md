This directory vendors the VADPCM codec used by `audioconv64`.

Upstream repository: https://github.com/depp/vadpcm  
Vendored from commit: `d2facb736fc57cdd01deafa65d37c76669526ac3`

Only the upstream `codec/` subtree is kept here (under `codec/`).

## Updating

Use `tools/audioconv64/vadpcm/update-vadcpm.sh`.

The script fetches upstream, computes a split of `codec/`, pulls only that subtree into `codec/`, refreshes `LICENSE.txt`, and then undoes the autogenerated subtree commit so changes are left staged for build/test.
