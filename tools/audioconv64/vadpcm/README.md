This directory vendors the VADPCM codec used by `audioconv64`.

Upstream repository: https://github.com/depp/vadpcm  
Vendored from commit: `3c462832e84294166b2034b8c420de4150753d12`

Only the upstream `codec/` subtree is kept here (under `codec/`).

## Updating

Use `tools/audioconv64/vadpcm/update-vadcpm.sh`.

The script fetches upstream, computes a split of `codec/`, pulls only that
subtree into `codec/`, refreshes `LICENSE.txt`, and then undoes the
autogenerated subtree commit so changes are left staged for build/test.
